コードを説明する際は、必ず以下の点を含めてください。

1. **例え話から始める**: コードを日常生活の何かと比較する
2. **図解を描いて説明する**: ASCIIアートを使って、流れ、構造、または関係性を示す
3. **コードを順を追って解説する**: 何が起きているかをステップバイステップで説明する。
4. **落とし穴を指摘する**: よくある間違いや誤解は何ですか？

図解は会話調を心がけてください。複雑な概念については、複雑な例えを用いると良いでしょう。
